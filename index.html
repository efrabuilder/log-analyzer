Log Analyzer

Parses router, switch and firewall logs, flags anomalies against configurable thresholds, and emails you before they become an outage.

View repository Quick start
py log_analyzer.py

What it does

Six things, done well, instead of a hundred half-finished ones.

Parsing

Multi-vendor log parsing

Reads router, switch and firewall log files without extra configuration.

Detection

Seven event types

Interface down, high CPU, auth failures, link flaps, memory warnings, and BGP/OSPF drops.

Tuning

Configurable thresholds

Set how many occurrences of each event type count as an anomaly.

Reporting

Color-coded Excel export

Events and anomalies land in separate sheets, ready to share with the team.

Alerting

Email alerts

Sends a summary the moment an anomaly crosses its threshold.

Interface

Clean CLI

Analyze a folder, specific files, or a directory with a single argument.

Detected events

Default thresholds — override any of them per deployment.

Quick start

From clone to first report in four steps.

# 1. Clone
git clone https://github.com/efrabuilder/log-analyzer.git
cd log-analyzer

# 2. Install
py -m pip install -r requirements.txt

# 3. Generate sample logs
py generate_sample_logs.py

# 4. Run
py log_analyzer.py
1

py log_analyzer.py — analyze the logs/ folder, the default.

2

py log_analyzer.py router.log switch.log — analyze specific files.

3

py log_analyzer.py --dir /var/log/network — point it at any directory.

4

py log_analyzer.py --summary --no-email — print a summary and skip alerts.
